# Лабораторная работа №1 — Вариант 4 «Животное»

Консольная программа на C++17 в стиле проекта `../lab1`.
Абстрактный класс `Base` описывает животное; от него открыто наследуются
`Fish` (рыба), `Bird` (птица) и `Cat` (кошка). Контейнер `Keeper` хранит
их в собственном динамическом массиве `Base**`, без `vector`, `list`
и других STL-контейнеров. Для текстовых полей, как и в исходной работе,
используется `std::string`.

## Поля варианта 4

| Тип | Характеристики |
| --- | --- |
| Рыба | Порода, окрас, тип питания |
| Птица | Порода, окрас, чем питается, где обитает |
| Кошка | Порода, окрас, ФИО владельца, кличка |

Общие поля `breed` и `color`, их get/set-методы находятся в `Base`.
У каждого наследника есть собственные поля, конструкторы без параметров,
с параметрами и копирования, деструктор, операторы `=` и `==`.
Конструкторы и деструкторы выводят сообщения в консоль.

## Сборка

Команды выполняются из папки `lab_1_4`.

Linux / macOS / Git Bash с установленным g++:

```bash
sh build.sh
```

```bash
./build/animals
```

Windows с g++ (MinGW / MSYS2), в командной строке:

```bash
cmd /c build.bat
```

```bash
./build/animals.exe
```

Через CMake:

```bash
cmake -S . -B build
```

```bash
cmake --build build
```

В Visual Studio или CLion можно открыть папку проекта и использовать
`CMakeLists.txt`; цель сборки — `animals`.

## Меню

1–3 — добавить рыбу, птицу или кошку; 4 — показать всех; 5 — показать
по номеру; 6 — изменить любое поле; 7 — удалить; 8 — дублировать;
9 — сравнить; 10 — сохранить в файл; 11 — загрузить из файла;
12 — очистить; 13 — переименовать контейнер; 14 — создать резервную
копию в памяти; 15 — восстановить её; 0 — выйти.

Все данные животных, номера объектов, название контейнера и имена файлов
задаёт пользователь. Объекты в меню нумеруются с единицы.

При загрузке примера через пункт 11 укажите `examples/animals_example.txt`,
если программа запущена из корня проекта; при запуске из `build`
укажите `../examples/animals_example.txt`.

Формат файла: `ANIMAL_KEEPER`, название, количество животных, затем блоки
с метками `FISH`, `BIRD`, `CAT` и соответствующими полями — по одному
значению на строке. Загрузка заменяет текущий список, а не дополняет его.
Ошибка загрузки не меняет текущие данные. При сохранении существующий файл
перезаписывается. Резервная копия существует только в памяти до выхода.
